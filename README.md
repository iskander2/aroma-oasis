\# AROMA OASIS



Интернет-магазин парфюмерии на Django.



\## О проекте



AROMA OASIS — учебный веб-проект интернет-магазина парфюмерии

с каталогом ароматов, выбором объёма, корзиной и оформлением заказов.



\## Возможности



\- Каталог парфюмерии

\- Поиск по товарам

\- Фильтрация по категориям

\- Выбор объёма: 5, 10, 20, 50 и 100 мл

\- Автоматическое обновление цены и остатка

\- Страницы с описанием ароматов

\- Корзина с AJAX-добавлением и удалением товаров

\- Регистрация и авторизация пользователей

\- Профиль и история заказов

\- Учёт остатков товаров

\- Панель администратора Django

- REST API на Django REST Framework
- Получение списка товаров и просмотр товара через API
- Создание заказов через API
- Просмотр своих заказов
- Отмена заказов с возвратом товара на склад
- Управление статусами заказов
- Авторизация через Token Authentication
- Разграничение прав доступа пользователей и администратора
- Автоматические API-тесты

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/iskander2/aroma-oasis.git
```

2. Перейдите в папку проекта:

```bash
cd aroma-oasis
```

3. Создайте виртуальное окружение:

```bash
python -m venv .venv
```

4. Активируйте виртуальное окружение (Windows):

```powershell
.venv\Scripts\Activate.ps1
```

5. Установите зависимости:

```bash
pip install -r requirements.txt
```

6. Выполните миграции:

```bash
python manage.py migrate
```

7. Запустите сервер:

```bash
python manage.py runserver
```

8. Откройте в браузере:

```text
http://127.0.0.1:8000/
```
